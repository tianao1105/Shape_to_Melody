# Shape to Melody
Draw something, hear melody. 

通过将用户画的形状转换为钢琴键来转换为旋律。

## 功能

- 绘画
- 将不规则图案或线条转换为可供读取的钢琴键
- 播放

## 绘画模式

- 正常画布
- 左右对称画布
- 万花筒（四象限镜像）

## 转化模式

- 全部转化（可选采样间隔）
- 部分转化（可上下拖动范围条选取区域）
- 随机转化
