# Shape to Melody
Draw something, hear melody. 

通过将用户画的形状转换为钢琴键来转换为旋律。
##功能：
   - 1.绘画
   - 2.转化由不规则的图案或者线条转换为可供读取的钢琴键
   - 3.播放
##绘画：
   - 1.正常画布格式
    -2.左右对称画布
   - 3.万花筒类似的四象限画布模式
##转化：
     - 1.全部转化（可选采样间隔）
     - 2.部分转化（绘画完后提供一个左右固定，上下可以滑动调节的透明范围进行转化）
     - 3.随机转化
